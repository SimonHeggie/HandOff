# HandOff v0.7.51 Alpha 1 — Naming and Compatibility Update

**Changes since [v0.7.50 Alpha 1](https://github.com/SimonHeggie/HandOff/releases/tag/v0.7.50-alpha.1)**

This release makes the established compositor exporter available under the **HandOff** identity. The original export capabilities are documented in the [initial release](https://github.com/SimonHeggie/HandOff/releases/tag/v0.7.50-alpha.1) and [user manual](https://github.com/SimonHeggie/HandOff/wiki).

## Changed in v0.7.51

- Renamed the displayed add-on and interface identity from **Comp-IO** to **HandOff**, including the tagline **“Hit render, go home.”**
- Renamed the installable Python package and module references from **`blend_psd_tools/`** to **`handoff/`**.
- Updated newly written SVG/source metadata identifiers to use the HandOff naming conventions; added compatibility handling for supported previously generated metadata.
- Retained established Blender RNA property identifiers and `blend_psd.*` operator IDs where needed for existing saved project settings and scripts.
- Updated legacy cache/job handling and environment-variable aliases for renamed installations, including **`HANDOFF_CACHE`** and **`HANDOFF_JOB_ROOT`**.
- Updated the bundled offline manual, development tests, documentation paths, dependency packaging and GitHub release build to use the new package name.

These are **naming, migration and packaging changes**. The layered-artwork formats and foundational export features were established in v0.7.50 and earlier alpha development; they are not newly introduced in this update.

## Upgrade from v0.7.50

1. Disable and uninstall the existing **Comp-IO / `blend_psd_tools`** add-on before installing HandOff; Blender treats the renamed module as a separate package, and both enabled together can register duplicate render handlers.
2. Download and install **`HandOff-v0.7.51-alpha.1-blender-addon.zip`** from the release's Assets section. Do not use GitHub's autogenerated source ZIP, which omits the bundled Pillow wheels.
3. Enable **HandOff** in Blender and verify destinations/preferences on a copy of your project. Package-specific preferences may need reconfiguration.

The release contains the renamed `handoff/` package and six verified Pillow 12.0.0 wheels for the supported CPython 3.13 platforms. The packaging workflow validates source syntax and archive integrity; a complete interactive Blender compatibility and cross-application round-trip test remains outstanding.

See the [migration notes](https://github.com/SimonHeggie/HandOff/blob/main/docs/RENAME_MIGRATION.md) for persistent identifier details.
