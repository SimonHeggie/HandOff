# HandOff v0.7.51 Alpha 1

**Hit render, go home.**

The first release under the **HandOff** name. This is the existing compositor-based layered asset exporter developed as Comp-IO, with the package, user-facing identity, generated identifiers and associated documentation renamed. **It is an alpha release, not a rewrite or a new Blender-to-Blender document/rig exporter.**

**Author:** Simon Heggie  
**Blender:** declares 5.0+ in `bl_info`; compatibility with individual builds must be tested  
**Download:** `HandOff-v0.7.51-alpha.1-blender-addon.zip` under Assets below. Use this installable ZIP, **not** GitHub's autogenerated source archive, which excludes bundled Pillow wheels.

## What this release actually exports

HandOff extends Blender's compositor **File Output** node with independent **Additional Outputs**. It builds document layers from the connected inputs, uses **Blender Collection ancestry** for grouping, and uses **socket order** for paint-layer order. It does not replace the original node's native render/file output.

| Output | Included functionality | Limitations |
| --- | --- | --- |
| **PSD / PSB** | Layered artwork, group structure, Collection-derived colour labels, supported blend modes and native representation of selected Grease Pencil/Curve/Text artwork | Some artwork becomes raster pixels or linked SVG sources. Complex vector gradients, effects and editor round trips are not universally supported. **32-bit float PSD/PSB is experimental.** |
| **OCA** | Layered still documents from **Render Image**; **Render Animation** captures the selected rendered frame range into one OCA document, with frame arrays, relative image assets, FPS and exposure durations | Uses rendered PNG/EXR layer artwork. Blender Frame Step becomes exposure holds; no scene rig/bone or transform-animation interchange. Other document destinations publish the final animation frame. |
| **SVG** | Layered SVG containing supported editable Grease Pencil, closed 2D Curve paths and live Text, including selected evaluated modifiers, fills, strokes, handles and clone relationships | Vector extraction needs **orthographic camera + Film Transparent**. Unsupported materials, masks, lighting, non-orthographic geometry and other effects use PNG fallback or reported approximations. |
| **PNG / TIFF / JPEG** | Per-input image exports or a flattened image | JPEG cannot retain alpha. Supported precision varies by format. |
| **OpenEXR** | Additional EXR output, including layered workflows | Multilayer/large images can require significant memory. |
| **Fonts / Text Assets** | Copies available referenced fonts and writes a `.fonts.json` manifest linking fonts and text objects | The optional Bfont-compatible OpenType asset **is not included**; original embedded `.pfb` extraction is attempted where available. |

The available output formats are `.PSD`, `.PSB`, `.OCA`, `.PNG`, `.SVG`, `.EXR`, `.TIFF`, `.JPEG` and `FONTS`. Not all bit depths or options apply to every format.

## Layered artwork and editing features

- **Hierarchy:** source Collections form grouped documents, respecting File Output input order. One Collection may be represented by multiple separated output groups when required to preserve stacking.
- **Authoring directives:** documented suffixes such as `.merge`, `.ungroup`, `.ignore`, `.ref`, `.add` and `.multiply` control grouping, visibility, omitted/reference material and blend behaviour without renaming Blender source objects.
- **Tag compatibility:** a per-destination choice between **No Conversion**, **Spine**, **Photoshop Generator** and **OCA / Krita**. These are naming/metadata conversions, **not** an export of Spine armatures, `.spine` projects or OCO rigs.
- **Editable vectors where supported:** Grease Pencil paths and evaluated supported modifiers, limited material gradients, pressure widths, native Curves and live Text can be represented as vector content. Some shared Grease Pencil datablocks can become SVG clones. The original shader/modifier logic does **not** execute in Photoshop or SVG.
- **Graceful fallback and diagnostics:** unsupported vector content retains rendered pixels, and certain PSD sources also retain links to separate SVG artwork. Conversion approximations and missing support are reported; target-editor display and editability still require testing.
- **Retained jobs:** **Check Export Status** previews the document hierarchy and checks tag compatibility. **Retry Export (No Render)** can republish supported destinations using retained cached artwork. **Clear Cache** deletes eligible retained jobs but does not remove published deliverables.

For details, see the [manual index](https://github.com/SimonHeggie/HandOff/blob/main/handoff/manual/MANUAL.md), [layer directives](https://github.com/SimonHeggie/HandOff/blob/main/handoff/manual/LAYER_TAGS.md), [blend mapping cautions](https://github.com/SimonHeggie/HandOff/blob/main/handoff/manual/BLEND_MODES.md), and [vector capability matrix](https://github.com/SimonHeggie/HandOff/blob/main/handoff/compatibility/vector_features.csv).

## What changed specifically in v0.7.51

Compared with **v0.7.50 Alpha**, this build primarily changes product identity and installation packaging:

- Product and visible add-on naming are now **HandOff**.
- The Python package and install directory are now **`handoff/`**, rather than `blend_psd_tools/`.
- Generated SVG/metadata identifiers have been adjusted for the renamed product, with handling for older metadata where implemented.
- Historical Blender RNA property names, `blend_psd.*` operator identifiers and selected old cache/job markers have been retained for compatibility with existing scenes and tools.
- Development tests, offline documentation and wheel-verifying release packaging were updated to the renamed package.

The major export features above were already developed in the v0.7 series; they should not be mistaken for newly added functionality in this naming release. For example, the v0.7.50 update introduced **OCA frame-sequence publication through Render Animation**, without adding rig extraction or animation deduplication.

## Installation and upgrade from Comp-IO

1. Download **`HandOff-v0.7.51-alpha.1-blender-addon.zip`** from this release.
2. In Blender, **disable and uninstall** the old `blend_psd_tools` / Comp-IO add-on *before* enabling HandOff. Blender sees these as separate packages; both active together can register duplicate render handlers.
3. Install the ZIP through **Edit > Preferences > Add-ons > Install from Disk**, enable HandOff, then select a compositor **File Output** node. Open **Node > HandOff - Additional Exports**.
4. Configure destinations, use **Check Export Status**, and test an export before using a production project. Old package-specific preferences may require reconfiguration.

The six bundled **Pillow 12.0.0** wheels are pinned/verified for supported **CPython 3.13** platforms. They do not establish support for Blender builds using Python 3.14 or other Python ABIs. The released ZIP includes those wheels; the repository's source ZIP does not.

See [migration details](https://github.com/SimonHeggie/HandOff/blob/main/docs/RENAME_MIGRATION.md).

## Known limitations and validation

- **Alpha status:** ZIP integrity and Python syntax were checked during release packaging. Local tests were run, but **full Blender UI/export integration and cross-editor round-trip validation were not completed** for this release.
- **Font delivery caveat:** the shipped package contains the Bfont verification metadata but **not** the optional `Bfont-Regular.otf` binary. Compatible OTF delivery is therefore unavailable in this build; the original embedded PostScript Bfont may still be extracted. Some historical manual passages describe the optional OTF as bundled and are outdated for this archive.
- **Format fidelity:** Blender shader networks, constraints, rig animation, masks and modifier systems cannot all be represented natively in PSD, SVG or OCA. Expect raster fallback, approximations or unsupported cases. Even matching blend-mode labels can behave differently between editors.
- **Not implemented yet:** generating an editable Blender document scene or standalone `.blend` handoff; evaluated scene-level animation isolation and capture for arbitrary destinations; direct OCO, Rive or Spine skeletal rig interchange; automated game/server/web deployment.
