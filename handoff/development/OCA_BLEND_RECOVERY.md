## Shader representation

A surface shader cannot discover arbitrary geometry behind itself. The supported
2D paint path explicitly samples imported lower artwork in shared shader groups:

- **OCA Artwork** contains the editable texture, native TexAnim sequence and
  opacity keys. Both the visible material and backdrop use this same group.
- Object texture coordinates follow the actual image-plane translation, rotation
  and scale, including per-frame crop dimensions. No duplicate image assets are
  generated by this shader path.
- **OCA Backdrop** recursively evaluates the imported bottom-to-top artwork.
- Native Mix Color nodes implement the paint function. Foreground colour is
  adjusted for backdrop alpha, then emitted through the existing transparency
  shader. Shine's one-child isolated Overlay group is represented on its plane.

For straight source colours B/F and alpha b/a, the target premultiplied RGB is:

```
(1-a)*b*B + a*((1-b)*F + b*blend(B,F))
alpha = a + (1-a)*b
```

Implemented node formulas: normal, multiply, add, screen, overlay, darken,
lighten, difference, exclusion and hard light. The first five plus isolated
Overlay are numerically rendered in the focused fixture; other formulas are
implemented but not newly certified by that fixture. No Screen/Add equivalence
or universal application/colour-profile equivalence is claimed.

An initial embedded Material tree-copy approach failed against Blender's actual
read-only embedded-ID API; it was removed. Cross-ID TexAnim drivers also produced
invalid depsgraph relations and were removed. Final code transfers the two native
animation channels into the shared sampler and reuses Bluik's existing TexAnim
handler. Final logs have no such RNA relation errors.

## Current boundaries

- Backdrop graphs follow the imported 2D layer order, not dynamically reordered
  arbitrary 3D geometry. Future depth/order capture needs explicit graph updates.
- Isolated multi-child group paint blending, overlapping group opacity and
  Inherit Alpha clipping remain limited and reported. Single-child isolated
  Shine Overlay is verified. Native GP behind a paint effect cannot yet be
  sampled by this image-plane path; it is explicitly reported as partial.
- These tests establish native Blender linear paint math using its actual sampled
  image values. They do not establish pixel identity with Krita/Photoshop ICC,
  gamma-blending choices or arbitrary display transforms.
- Other blend names retain metadata and warn when unsupported; they are not
  silently advertised as supported native shaders.
- No sequencing optimisation, rig/weight capture, VSE export or new OCA transform
  fields were added. Those are the subsequent roadmap, not changes in this repair.

Restart Blender to load changed modules. Existing imported objects do not change
retroactively. Retry Export Without Rendering recaptures current visibility;
reimport that OCA, or open the tested Blender example above.
