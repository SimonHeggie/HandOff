Group and export directives

HandOff reads the supported Collection and output-name directives when assembling the export. The detailed entries below show how the same functions are represented in Spine, Photoshop Generator and OCA.

A Collection with .merge is rasterised to one paint layer. The exported paint layer takes the Collection name with the suffix removed. Child outputs are composited in their File Output order.

Artwork.merge
  Base
  Details

Export: Artwork (paint layer)

.ungroup removes a Collection container and promotes its children to the next retained ancestor. .ignore omits its subtree. .ref keeps reference artwork hidden in PSD and marked as reference in OCA.

Do not use .merge and .ungroup together on the same Collection. A merge applies to a consecutive group run, preserving the overall layer order. Merging layers with backdrop-dependent blends may change the composite.

Ignore / omit on export

Do not include a layer or group in the target export. Scope: layer,group.

DestinationSupportActual tag / syntaxNotes
Spinenative[ignore]Spine import ignores target and descendants.
Photoshop Generatornone-Generator has no standalone ignore directive. An ordinary layer name without asset filename will not itself trigger an asset.
OCA / Kritanative_ignore_Krita exporter excludes the layer; native OCA writer omits it.

Blender authoring: .ignore

Caution: Spine [ignore] can preserve a visible PSD reference, whereas excluding a layer from the PSD removes it completely.

Reference / guide artwork

Keep for the artist but mark non-rendering/non-exporting downstream. Scope: layer,group.

DestinationSupportActual tag / syntaxNotes
Spineapproximation[ignore]Spine has no reference tag; [ignore] stops importer from creating an attachment.
Photoshop Generatornone-No Generator reference directive; keep a normal hidden layer without a Generator filename.
OCA / Kritanative_reference_Krita OCA exporter marks a reference; native OCA layer.reference=true.

Blender authoring: .ref

Caution: Reference artwork can remain available as a guide. Spine [ignore] omits it on import, while OCA marks it as reference content.

Merge a group into one paint layer

HandOff rasterizes a tagged Blender Collection into one PSD/OCA pixel layer. Its name comes from the group, with .merge removed. Multiple child render layers are composited in their stack order. Scope: group,layer.

DestinationSupportActual tag / syntaxNotes
Spinepartial[merge]Spine [merge] asks its importer to flatten an existing PSD group. HandOff .merge is applied during PSD creation, resulting in one paint layer.
Photoshop Generatorapproximation-Generator flattens a group only into a generated asset file; it does not change the PSD layer hierarchy.
OCA / Kritanative_merge_Krita OCA export can flatten tagged groups. HandOff writes already merged pixels in native OCA.

Blender authoring: .merge

Caution: HandOff merges cached pixels without changing Blender geometry. Mixed group blend modes can look different after flattening when they depend on backdrop artwork outside the group. Test complex compositing before delivery.

Preserve layer hierarchy

Keep authored parent/child grouping. Scope: group.

DestinationSupportNotes
SpinemetadataSpine [folder] controls the attachment output directory. PSD groups retain their own hierarchy.
Photoshop GeneratormetadataGenerator can use any group for compositing but does not use arbitrary folder names as paths.
OCA / KritametadataNative OCA expresses groups structurally; no naming tag required.

Blender authoring: .ungroup

Caution: Group membership must preserve original draw order; noncontiguous hierarchy needs split group instances.

Hidden / initial visibility

Preserve artwork but open it hidden. Scope: layer,group.

DestinationSupportNotes
SpinemetadataSpine can optionally ignore hidden layers on import.
Photoshop GeneratormetadataPhotoshop Generator follows the normal layer visibility settings when producing assets.
OCA / KritametadataNo OCA name tag needed.

Blender authoring: .hidden

Asset image subfolder

Place extracted image assets within a directory structure. Scope: layer,group.

Caution: Grouping folders can organise artwork without creating an asset output directory.
