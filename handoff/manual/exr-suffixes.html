Layer blend modes

HandOff accepts dot suffixes on authored names, including blend modes such as .add and .multiply. They use a dot-separated naming pattern familiar from OpenEXR channels. Their behaviour is defined by HandOff.

HandOff interprets recognised dot suffixes on authored output names. A suffix can specify a blend mode or an export operation. It is removed from the displayed layer name after the instruction is applied.

Highlight.add -> Highlight (Add)
Shadow.multiply -> Shadow (Multiply)

If a strict majority of a group's direct pixel layers use the same non-Normal blend mode, HandOff can apply that mode to their group and set the affected children to Normal. Check the composite when mixing modes or working between editors.

OpenEXR commonly uses dot-separated channel identifiers such as Layer.R. HandOff's dot suffixes are authoring directives defined by HandOff; OpenEXR channel names have separate semantics.
