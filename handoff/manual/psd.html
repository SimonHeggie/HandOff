PSD and PSB colour handling

For 8-bit and 16-bit display-referred PSD/PSB exports, HandOff embeds the PNG source ICC profile when present and otherwise assigns sRGB. The 16-bit path preserves the PNG channel values during transfer.

32-bit exports preserve scene-linear HDR pixels. The standard Blender Rec.709 working space uses a corresponding linear RGB ICC profile. When a custom OCIO override is detected, the writer reports this and leaves the profile unassigned.

PSD and PSB support group and paint-layer colour labels. HandOff reads Collection colour tags and applies the nearest supported Photoshop label colour. Editor support for displaying those labels varies.
