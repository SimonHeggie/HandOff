Trim uses nonzero alpha bounds, then scales and adds symmetric transparent padding. Frame centres retain their exact scaled position. Scale above 100% uses ordinary raster resampling, not AI enhancement; SVG remains scalable vector artwork. Blank frames use the standard OCA blank convention. Retry applies current options to all captured frames without rendering.

Background detection requires an explicit source View Layer custom property handoff_oca_background=True. Names and bottommost placement are never used.

GP SVG artwork and PNG alternatives

Supported direct GP compositor inputs publish individual SVG vector layers. Unsupported artwork and compositor processing retain native rendered pixels. Rasterise Vector Layers selects rendered paint layers. With Keep Alternative Artwork off, each logical layer delivers only its selected PNG/EXR or SVG representation. Enable Keep Alternative Artwork explicitly to retain the unselected editable SVG or rendered PNG too; it never adds a second visible layer.

Only explicitly retained alternative assets live under _raster/ or _vectors/. Their references use custom HandOff data inside the standard frame meta object; OCA has no native alternative-attachment selector. SVG and PNG use the same processed rectangle and centre. Write Spine JSON is optional and off by default: its non-OCA files live in _companions/ and any required additional previews are confined to _companions/images/. Write template image uses temporary previews without adding duplicate OCA assets. Disable both companion controls and Keep Alternative Artwork for a clean OCA-only project. Existing explicitly saved settings are preserved. For floating-point sources, these PNGs are 16-bit display previews while ordinary EXR cels preserve HDR precision.

If a direct GP-only source renders empty in the multi-view cache but succeeds alone, an initial export can recover pixels using its captured native Blender source. Retry never performs that render. Existing layer-order numbering is removed from asset filenames; frame numbers and collision-safe suffixes remain.

OCA references and authoring

In View Layer Properties, open HandOff — OCA Authoring. These controls apply to OCA exports. Existing Blender material/drawing transparency remains baked into the artwork; Export Opacity and Frame Opacity are additional OCA opacity.

Control/workflowBehaviour
Linked Grease Pencil duplicatesPlace linked copies of one GP datablock in separate View Layers and connect their Image outputs. HandOff emits OCA clone references only after verifying shared identity, matching evaluated styling/geometry and a constant translation with matching crop. Independent copies and unsupported rotations remain independent SVG artwork.
Keep IndependentDisable automatic OCA clone conversion for this input.
Source View LayerExplicitly reference one uniquely connected source View Layer. Missing, ambiguous and cyclic references fail validation. No matching by similar artwork names.
Reference Offset / Time OffsetTranslate references in document pixels (X right, Y down). Positive time offsets delay the referenced artwork. These are standard OCA positions/offsets, not pivot, rotation or scale animation.
Nested OCA DocumentPublish an ocalayer. The referenced document graph, artwork and metadata are copied into the project. Source Layer ID optionally selects one layer. Export Scale applies consistently; nested assets retain their own cropping/padding.
Export Opacity / Frame OpacityIndependent layer opacity and animatable exposure opacity. Retry reevaluates current authoring values against the existing render cache.
Inherit Alpha / OCA BlendWrite the standard OCA clipping/blend properties. From Source retains existing suffix/group rules. Explicit OCA overrides affect this destination only. Target-editor blend definitions can differ, particularly Soft Light.
OCA BackgroundIndependent document RGBA colour. Alpha zero keeps the document transparent.
Collection Properties → HandOff — OCA GroupSet group opacity, alpha inheritance, blend or isolation. Opacity/clipping forces isolated composition where required. Collection hierarchy and colour labels are preserved.

Templates understand clone/nested references, group isolation and alpha inheritance. An unsupported template blend or SVG without a rendered companion is reported rather than replaced by a blank image. The native OCA artwork is retained.

The Bluik Plus development integration has been tested with actual SVG/GP frames, cropped images, shared-data edits, time offsets and reopening. Its 3D preview still approximates isolated overlapping-group opacity and paint blending, and retains Inherit Alpha as metadata without native plane clipping. Legacy pivot prototypes remain separate from OCA 1.3.
