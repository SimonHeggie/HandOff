Make one layered file first

HandOff turns the image inputs on a Blender File Output node into deliverables such as a layered PSD, SVG or OCA animation.

Goal: render once and find a layered document in your chosen folder.
  1. Install and enable HandOff. Use the complete installable ZIP in Blender Preferences, not GitHub’s source ZIP. Restart Blender after an upgrade.
  2. Open the Compositor. Connect the artwork images you want to a File Output node. A Render Layers node supplies each source image.
  3. Select that File Output node. Open its Node sidebar and expand HandOff - Additional Exports.
  4. Add one destination. Press +, select .PSD, and choose its Directory. Enable Use Groups to retain Collection folders. Leave Flatten Image off for separate layers.
  5. Check the result before rendering. Open Additional Output Paths and use Check Export Status to review the path and layer grouping.
  6. Render an image (F12). Wait for conversion to finish, then open the PSD from the displayed path.

Expected result: a PSD containing the connected artwork. The native File Output continues writing its own configured files.

Choose your next task

  • Put layers into useful folders.
  • Choose a different deliverable.
  • Export an animation.
  • Fix a failed export or retry cached pixels.
What can stay at its default?

Leave Tag Compatibility on No Conversion unless another tool requires specific naming. You do not need Spine tags, Photoshop Generator expressions or XML knowledge for a first export.

Completion Chime Volume is optional. Zero disables sound loading. Detailed diagnostics stay folded away until needed.
