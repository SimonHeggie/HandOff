Collections become document folders

File Output inputs select the artwork and its stack order. Source Collections supply folder names and colour labels. HandOff traces the connected source; renaming a socket alone does not change which Blender objects it renders.

  1. Organise the source objects into Collections.
  2. Connect each desired artwork image to the File Output node.
  3. Enable Use Groups on the destination.
  4. Use Check Export Status to inspect the proposed hierarchy.

Expected result: the exported document contains the retained Collection folders and their artwork. A group and its child paint layer may legitimately share a name.

Repeated groups and ambiguous sources

Interleaved compositor inputs can split a Collection into separate group runs to retain paint order. HandOff uses a relevant child name when a repeated folder needs distinguishing. An input covering several Collections can remain at the root rather than being assigned by guesswork.

Colour labels are organisational

Paint layers follow their owning Collection. An explicitly untagged Collection stops ancestor colour inheritance. SVG highlights use white for untagged content; PSD uses its native Grey label. The receiving application decides which labels it displays, especially for groups. A missing Krita group swatch alone does not prove that the PSD metadata is absent.

To merge, remove or hide selected exported containers, use the export directives.
