Spine naming compatibility

Optional reference for another application. HandOff does not export a Spine skeletal rig.

The bracketed tokens in this section are interpreted by the Spine PSD importer. HandOff applies the corresponding conversion only when the destination selects Spine compatibility.

Slot assignment

Assign attachments to named Spine slots. Scope: layer,group.

DestinationSupportActual tag / syntaxNotes
Spinenative[slot]Closest ancestor slot applies.
Photoshop Generatornone-No direct equivalent; preserve original expression and warn.
OCA / Kritanone-No direct equivalent; preserve original expression and warn.

Blender authoring: .slot:name

Spine attachment image path

Override attachment image path independently from layer name. Scope: layer,merged-group.

DestinationSupportActual tag / syntaxNotes
Spinenative[path:name]Slash at start makes path absolute relative to image root; different from Generator asset path.
Photoshop Generatornone-Generator paths are full output filename specifications, with file extensions.
OCA / Kritametadata-OCA stores the frame image path in metadata.
